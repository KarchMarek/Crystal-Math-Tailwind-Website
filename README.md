# 🧮 Crystal Math Tailwind Website

**(Tailwind CSS · Vite · Responsive Design · Utility-First CSS · GitHub Pages)**

A modern responsive landing page built with Tailwind CSS and Vite. This educational portfolio project was created while following a tutorial as part of my journey learning Tailwind CSS, focusing on utility-first styling, responsive layouts, and the Vite development workflow.

[🔗 **Live Preview**](https://karchmarek.github.io/Crystal-Math-Tailwind-Website/)

---

## 🎯 Project Goal

The main goal of this project was to practice the Tailwind CSS concepts learned while following a tutorial and apply them to a complete responsive website.

The project focuses on utility-first CSS, responsive design, flexible layouts, custom styling, and understanding how Tailwind CSS works together with Vite.

---

- Responsive design with Tailwind breakpoints
- Flexbox layouts
- Responsive typography and spacing
- Custom colors and background effects

## 🛠️ Tech Stack

## 📱 Responsive Design

The website is designed to adapt to different screen sizes and devices.

Responsive styling was implemented using:

- Tailwind CSS responsive breakpoints
- Flexible layouts with Flexbox
- Responsive typography
- Responsive spacing and sizing
- Responsive buttons and content positioning
